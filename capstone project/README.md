# GUVI Web Automation (PAT WebCode-1)

## 📌 Project Overview
This project automates the [GUVI](https://www.guvi.in) website using **Selenium and Pytest**.

## 🛠️ Tech Stack
- **Python** (for scripting)
- **Selenium WebDriver** (for automation)
- **Pytest** (for test execution)
- **Pytest-HTML** (for report generation)
- **PyLint** (for code quality)
