# GUVI Web Automation (PAT WebCode-1)

## 📌 Project Overview
This project automates the [GUVI](https://www.guvi.in) website using **Selenium and Pytest**.

## 🛠️ Tech Stack
- **Python** (for scripting)
- **Selenium WebDriver** (for automation)
- **Pytest** (for test execution)
- **Pytest-HTML** (for report generation)
- **PyLint** (for code quality)

## 📂 Folder Structure
PAT-WebCode-1/ │── pages/ # Page Object Model (POM) files │── tests/ # Test cases │── utils/ # Utility files (config, logger) │── reports/ # Test reports and logs │── conftest.py # Pytest fixture setup │── requirements.txt │── README.md │── pytest.ini │── .pylintrc
